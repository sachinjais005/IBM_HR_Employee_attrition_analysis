# IBM HR Analytics Dashboard

## 📌 Project Overview
This project analyzes the IBM HR Analytics dataset to understand employee attrition, workforce distribution, and key HR metrics. The analysis was performed using Python, SQL, and Power BI to generate business insights and support data-driven decision-making.

## 🎯 Objectives
- Analyze employee attrition trends
- Understand workforce demographics
- Identify factors affecting employee retention
- Build an interactive Power BI dashboard
- Generate actionable business recommendations

## 📂 Dataset
- Dataset: IBM HR Analytics Employee Attrition
- Source: IBM Sample Dataset
- Format: CSV
- Total Records: 1,470 Employees

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Microsoft Excel
-Gen AI

## 📊 Dashboard Features
- Employee Overview
- Attrition Analysis
- Department-wise Distribution
- Gender Analysis
- Education Field Analysis
- Business Travel Analysis
- Job Role Analysis

## 🔍 Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights
6. Power BI Dashboard Development
7. Documentation

## 💡 Key Insights
- Overall employee attrition rate is approximately 15.9%.
- Research & Development has the largest workforce.
- Life Sciences is the most common education field.
- Most employees travel rarely for business.
- Sales Executive is one of the largest job roles.

## ✅ Recommendations
- Improve employee retention strategies.
- Focus on departments with higher attrition.
- Enhance employee engagement programs.
- Monitor attrition trends regularly.
